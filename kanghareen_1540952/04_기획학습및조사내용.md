# 기획 과정 학습 및 조사 내용

## 1. Edge AI

Edge AI는 카메라 영상을 로봇 내부에서 우선 분석하여 필요한 데이터만 서버로 전송하는 방식입니다.

### 프로젝트 적용

- Jetson Orin Nano에서 파손 후보 탐지
- 정상 영상은 순환 버퍼에서 자동 폐기
- 파손 이벤트 영상과 대표 이미지만 저장
- 네트워크 사용량과 서버 저장 공간 절감
- 개인정보 보관 범위 최소화

## 2. AI 데이터 및 학습 계획

### 활용 예정 공개 데이터

- 보행 안전을 위한 도로 시설물 데이터: 약 3.56TB
- 인도보행 영상 데이터: 약 607.40GB
- 원천 데이터 전체 규모: 약 4.17TB

전체 데이터를 모두 학습하지 않고 점자블록과 보행로 관련 데이터를 선별·전처리하여 활용할 예정입니다.

### 자체 데이터 수집

- 정상 점자블록
- 균열 및 깨짐
- 일부 결손과 누락
- 위치 이탈
- 그림자와 오염
- 노란색 일반 보도블록
- 맨홀·경계석·적치물 등 오탐 환경

### 학습 방향

- YOLO 계열 객체 탐지 모델 검토
- 학습·검증 데이터 분리
- 오탐·미탐 분석 후 추가 수집 및 재학습
- Jetson 적용을 위한 모델 최적화

## 3. 자율주행 및 센서

### 주요 구성

- X4 Pro LiDAR: 장애물 감지 및 위치 추정 보조
- 카메라: 점자블록 영역과 파손 상태 촬영
- IMU: 방향 및 기울기 측정
- 휠 엔코더: 이동거리 계산
- GPS/GNSS: 야외 위치 좌표 수집
- Jetson Orin Nano: AI 추론 및 데이터 처리
- MCU·모터 드라이버: 로봇 주행 제어

### 기획 시 확인한 위험요소

- 햇빛과 그림자로 점자블록 인식 실패 가능
- 노란색 물체 오탐 가능
- GPS 위치 오차
- 주행 중 영상 흔들림
- Jetson 전력·발열 문제
- 모터 전원 노이즈가 센서에 미치는 영향

## 4. 관리자 서비스

관리자는 다음 기능을 사용하도록 기획했습니다.

- 지도 기반 파손 위치 확인
- 파손 이미지 및 상세 결과 조회
- 보수 필요성 확인
- 처리 상태 변경
- 기간별 통계 확인
- 점검 결과서 및 보수 검토 신청서 초안 다운로드

## 5. PM 학습 내용

이번 기획 과정에서 기술 기능을 단순히 나열하는 것보다 다음 사항이 중요하다는 점을 학습했습니다.

- 사용자의 실제 문제와 기능을 연결해야 합니다.
- AI가 판단할 수 있는 범위와 담당자 확인이 필요한 범위를 구분해야 합니다.
- 기술적 욕심보다 6주 내 구현 가능한 MVP를 먼저 정의해야 합니다.
- 하드웨어, AI, 서버, 웹 개발 일정을 병렬로 관리해야 합니다.
- 데이터·장비·전원 등 개발 자원을 기획 단계에서 미리 확인해야 합니다.
