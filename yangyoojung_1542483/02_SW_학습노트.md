## 2. RPi.GPIO

### 2.1 RPi.GPIO란

RPi.GPIO는 Python으로 라즈베리파이의 GPIO 핀을 제어하는 라이브러리

LED 켜기, 터치센서 읽기, 간단한 PWM 출력 등에 사용


### 2.2 Raspberry Pi 5 주의사항

기존 `RPi.GPIO`는 오래된 라즈베리파이에서 널리 사용한 라이브러리임.

하지만 Raspberry Pi 5의 새로운 GPIO 구조를 직접 지원하지 않음.

Raspberry Pi 5에서는 다음 대안을 우선 고려함.

- 초보자가 사용하기 쉬운 `gpiozero`
- 기존 `RPi.GPIO` 코드와 비슷한 방식의 `rpi-lgpio`

`rpi-lgpio`는 코드에서 `import RPi.GPIO as GPIO` 형태를 유지할 수 있는 대체 구현임.

기존 `RPi.GPIO`와 `rpi-lgpio`는 같은 이름 공간을 사용하므로 두 패키지를 동시에 설치하면 충돌할 수 있음.

새로운 Raspberry Pi 5 프로젝트라면 공식 문서에서 안내하는 GPIO Zero 사용도 좋은 선택임.

## 3. OpenCV

### 3.1 OpenCV란

OpenCV는 사진과 영상을 읽고 가공하는 컴퓨터 비전 라이브러리임.

컴퓨터 비전은 컴퓨터가 사진과 영상을 처리하도록 만드는 기술 분야임.

OpenCV가 자체적으로 모든 물체의 의미를 이해하는 것은 아님.

영상의 크기 변경, 색상 변환, 선 그리기, 카메라 입력 같은 기능을 제공함.

YOLO와 함께 사용하면 카메라 영상을 읽고 탐지 결과를 화면에 표시할 수 있음.

## 4. PyTorch

### 4.1 PyTorch란

PyTorch는 딥러닝 모델을 만들고 학습하고 실행하는 라이브러리

YOLO 같은 AI 모델의 내부 계산을 담당하는 엔진과 비슷

### 4.2 Tensor

Tensor는 PyTorch가 사용하는 여러 차원의 숫자 묶음임.

처음에는 숫자가 들어 있는 상자라고 이해하면 됨.

```text
0차원 Tensor = 숫자 하나
1차원 Tensor = 숫자 목록
2차원 Tensor = 표
3차원 Tensor = 컬러 이미지와 같은 구조
```


### 4.3 젯슨 설치 주의점

젯슨은 일반 PC와 CPU 구조와 CUDA 환경이 다를 수 있음.

무조건 최신 PyTorch를 설치하면 JetPack의 CUDA와 맞지 않을 수 있음.

JetPack 버전에 맞는 PyTorch 설치 파일 또는 컨테이너 사용을 권장

## 5. torchvision

### 5.1 torchvision이란

torchvision은 PyTorch에서 이미지 작업을 편하게 해주는 보조 라이브러리

PyTorch가 딥러닝의 기본 엔진이라면 torchvision은 이미지 작업용 도구 상자

### 5.2 주요 기능

| 기능 | 설명 |
| --- | --- |
| datasets | 자주 사용하는 이미지 데이터셋 불러오기 |
| transforms | 이미지 크기와 형식 변경, 정규화 |
| models | 이미지용 사전 학습 모델 제공 |
| io | 이미지 읽기와 저장 |
| utils | 바운딩 박스 그리기와 결과 저장 |


### 5.3 PyTorch와 버전 호환

PyTorch와 torchvision은 서로 맞는 버전 조합 사용이 중요함.

맞지 않는 버전을 설치하면 연산자 또는 확장 기능을 찾지 못하는 오류가 발생할 수 있음.

젯슨에서는 JetPack, CUDA, PyTorch, torchvision까지 함께 호환성 확인이 필요함.

## 6. Ultralytics

### 6.1 Ultralytics란

Ultralytics는 YOLO 모델을 쉽게 학습하고 실행할 수 있도록 만든 Python 패키지

PyTorch를 직접 다루는 복잡한 코드를 줄이고 몇 줄의 코드로 객체 탐지를 실행할 수 있음.

### 6.2 PyTorch와의 관계

```text
사용자 코드
    ↓
Ultralytics의 쉬운 YOLO 기능
    ↓
PyTorch의 Tensor와 딥러닝 계산
    ↓
CPU 또는 NVIDIA GPU
```

Ultralytics와 PyTorch는 경쟁하는 별도 기능이라기보다 위아래에서 함께 동작하는 관계


### 6.3 성능에 영향을 주는 항목

- 모델 크기
- 입력 이미지 해상도
- CPU 또는 GPU 사용 여부
- TensorRT 최적화 여부
- 카메라의 초당 프레임 수
- 동시에 실행 중인 프로그램
- 젯슨 전력 모드와 온도

정확도를 높이면 속도가 느려질 수 있으며 속도를 높이면 작은 물체를 놓칠 수 있음.

## 7. socket

### 7.1 socket이란

`socket`은 Python 프로그램이 네트워크로 데이터를 주고받게 하는 표준 라이브러리임.

소켓은 네트워크 통신 창구이며 IP 주소와 Port 번호를 이용해 상대 프로그램을 찾음.

### 7.2 TCP 서버 흐름

```text
socket()  → 통신 창구 생성
bind()    → 서버의 IP와 Port 지정
listen()  → 연결 대기 시작
accept()  → 클라이언트 연결 수락
recv()    → 데이터 수신
sendall() → 데이터 전송
close()   → 연결 종료
```

### 7.3 실제 프로젝트에서 필요한 처리

- 연결 시간 제한
- 서버 연결 실패 처리
- 연결이 끊어진 경우 재연결
- 잘못된 JSON 처리
- 같은 데이터의 중복 전송 처리
- 중요한 데이터의 로컬 임시 저장
- 인증과 암호화
- 여러 클라이언트의 동시 연결 처리

## 8. RPLCD

### 8.1 RPLCD란

RPLCD는 Python으로 문자 LCD를 제어하는 라이브러리

HD44780 계열 문자 LCD와 I2C 변환 모듈 제어에 사용

`01_HW_학습노트.md`에서 다룬 I2C LCD에 글자를 표시할 때 사용 가능함.

### 8.2 I2C LCD의 구조

일반적인 I2C LCD는 문자 LCD 뒤에 PCF8574 같은 I2C 변환 칩을 붙인 형태임.

```text
라즈베리파이
    ↓ I2C 통신
PCF8574 변환 칩
    ↓ LCD 제어 신호
문자 LCD
```

## 9. Flask

### 9.1 Flask란

Flask는 Python으로 웹 서버와 HTTP API를 만드는 라이브러리임.

웹 브라우저에서 센서값을 확인하거나 스마트폰 앱이 오린카의 위험 정보를 전송하는 기능 제작에 사용 가능함.

### 9.2 웹 서버와 웹 브라우저

```text
웹 브라우저 또는 앱 = 요청을 보내는 클라이언트
Flask 프로그램       = 요청을 받고 응답하는 서버
```

예를 들어 브라우저가 `/temperature` 주소를 요청하면 Flask가 현재 온도를 돌려주는 방식임.


### 9.3 Flask와 socket의 관계

Flask도 내부적으로 네트워크 소켓과 TCP를 사용함.

차이는 개발자가 다루는 수준임.

| socket | Flask |
| --- | --- |
| TCP 데이터 형식을 직접 정함 | HTTP 규칙을 사용함 |
| 연결과 송수신을 직접 처리함 | 주소와 함수 중심으로 처리함 |
| 자유도가 높음 | 웹과 앱 연결이 편리함 |
| 메시지 경계를 직접 정해야 함 | HTTP가 요청과 응답 구조를 제공함 |

처음 서버 API를 만들 때는 Flask가 이해하기 쉬움.

장치 간 전용 통신 규칙이 필요하면 socket 직접 사용도 가능함.
