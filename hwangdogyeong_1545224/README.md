실제 내려받은 **학습 라벨**을 전수 검사한 결과 817,586개 JSON 중 점자블록 이미지 23,475개를 선별했다. 점자블록 주석은 51,721개로 모두 polygon이었으며, 중복 이미지 ID/파일명은 발견되지 않았다. 전체 통계 30,000장과 차이가 나는 이유는 현재 파일이 학습 라벨 묶음이므로 검증 데이터 배포분을 별도로 확인해야 한다.

## 핵심 결론

MVP에서는 한 모델로 모든 문제를 해결하기보다 다음의 2단계 구조가 적합하다고 판단했다.

1. **Edge 모델:** 경량 객체 탐지/세그멘테이션 모델로 점자블록 및 파손 후보를 빠르게 선별한다.
2. **서버 모델:** 고해상도 crop을 이용해 파손 여부와 심각도를 정밀하게 분석한다.

우선 베이스라인은 YOLO 계열의 작은 모델로 시작하고, Jetson에서는 ONNX 및 TensorRT 변환을 통해 지연시간과 메모리 사용량을 측정한다. 작은 균열처럼 경계 모양이 중요한 문제는 bbox만으로 한계가 있으므로 세그멘테이션 모델을 비교 실험한다.
