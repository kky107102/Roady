# 황도경(1545224) 이번 주 공부·작업 기록

## 내가 맡은 부분

- AI·데이터 파트
- AI Hub 점자블록 데이터 확인과 전처리
- 점자블록 파손을 찾을 비전 모델 조사
- Jetson Orin Nano에서 모델을 돌리기 위해 필요한 내용 공부

아직 프로젝트 이름은 정하지 못했고, 주제는 **점자블록 파손 점검 자율주행 AI 로봇 시스템**으로 정했다. AI 파트를 맡았는데 처음에는 단순히 YOLO만 학습하면 되는 줄 알았다. 기획서를 구체화하면서 실제로는 데이터 라벨 구조, Edge와 서버의 역할, 카메라 환경, Jetson 성능까지 같이 봐야 한다는 것을 알게 되어 관련 내용을 순서대로 찾아봤다.

현재 확보한 것은 **Training 라벨 배포 ZIP**이다. 이 ZIP 내부의 `TL1~TL33`을 구조 확인 목적으로 읽어 본 결과 817,586개 JSON 중 점자블록 라벨 23,475개를 선별했다. 점자블록 annotation은 51,721개로 모두 polygon이었고 중복 이미지 ID/파일명은 발견되지 않았다. 다만 원천 이미지는 아직 확보하지 못했기 때문에 이미지와 라벨이 실제로 짝이 맞는지는 검증하지 못했다.

현재 원천데이터는 `TS8`, `TS9`를 다운로드하고 있고 아직 완료되지 않았다. Validation 원천데이터와 라벨데이터도 아직 확보하지 못했다. 따라서 위 통계는 **학습 완료 데이터 수가 아니라 라벨 ZIP만 읽어 본 결과**이며, 모델 학습을 진행했다는 의미는 아니다.

추가로 AI Hub의 **인도보행 영상(dataSetSn=189)**도 학습에 사용하기 위해 다운로드하고 있다. 이 데이터에는 점자블록 `normal/damaged` Surface Masking뿐 아니라 사람, 자전거, 볼라드 등 보행 장애물 29종과 스테레오 Depth 데이터가 포함되어 있다. 우선은 점자블록 파손 mask를 기존 데이터와 함께 사용하고, 장애물·Depth 데이터는 자율주행 파트와 협의한 뒤 별도 모델 또는 후속 기능으로 검토할 예정이다.

## 공부하면서 바뀐 생각

처음에는 파손을 찾는 모델 하나만 만들면 된다고 생각했다. 그런데 정상 주행 영상을 전부 서버에 보내면 저장 공간과 통신량이 너무 커지고, 반대로 Jetson에서 모든 것을 정확하게 판단하려고 하면 속도가 문제가 될 수 있다. 그래서 현재는 다음처럼 두 단계로 나누는 쪽을 생각하고 있다.

1. **Edge 모델:** 경량 객체 탐지/세그멘테이션 모델로 점자블록 및 파손 후보를 빠르게 선별한다.
2. **서버 모델:** 고해상도 crop을 이용해 파손 여부와 심각도를 정밀하게 분석한다.

우선 YOLO 계열의 작은 모델로 시작해 보고, Jetson에서 실제 FPS와 지연시간을 재볼 예정이다. 작은 균열은 네모난 bbox만으로 면적을 잡기 어려워 보여서 Detection과 Segmentation을 둘 다 해 보고 결정하려고 한다.
