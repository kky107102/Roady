## 1주차 핵심 성과

1. 일반 보도블록 파손 탐지에서 **점자블록 특화 유지관리 서비스**로 주제를 구체화했습니다.
2. 자율주행 로봇, Edge AI, 서버 분석, 관리자 웹을 연결한 전체 서비스 흐름을 설계했습니다.
3. MVP 범위를 점자블록 파손 유무 탐지 중심으로 축소하고 향후 확장 기능을 분리했습니다.
4. AI 학습용 공개 데이터와 자체 촬영 데이터 활용 계획을 수립했습니다.
5. 팀 회의를 진행하고 컨설턴트·코치 피드백을 반영하여 구현 범위와 질문 목록을 정리했습니다.
