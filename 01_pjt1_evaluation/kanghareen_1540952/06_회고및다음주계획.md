# 1주차 회고 및 다음 주 계획

## KPT 회고

| 항목 | 내용 |
|---|---|
| Keep | 기획서 작성과 팀 회의를 통해 아이디어를 구체화했습니다. 컨설턴트님과 코치님의 피드백을 바로 기획에 반영했습니다. |
| Problem | 해야 할 일이 많아 마음이 급해졌고, 여러 업무를 동시에 처리하며 집중이 분산되었습니다. GPU 서버 등 필요한 자원을 더 일찍 확인하지 못했습니다. |
| Try | 업무를 중요도와 마감순으로 정리하고 담당자를 명확히 나누겠습니다. 회의 결과와 필요한 자원을 체크리스트로 관리하겠습니다. |

## 2주차 목표

1. RC카 기본 하드웨어 제작과 센서 점검을 시작합니다.
2. 점자블록 데이터 수집 및 라벨링 기준을 확정합니다.
3. 공개 데이터 중 실제 사용할 범위를 선별합니다.
4. 백엔드·프론트엔드 기술 스택과 데이터 흐름을 확정합니다.
5. 관리자 웹 와이어프레임과 API 명세 초안을 작성합니다.
6. 팀원별 주간 목표와 완료 기준을 정리합니다.

## PM 개인 실천 계획

- 매일 오전 우선순위 3개를 정리합니다.
- 회의 종료 후 결정사항과 담당자를 바로 기록합니다.
- 일정 지연 가능성이 있는 업무를 조기에 확인합니다.
- 팀원의 기술 의견을 서비스 요구사항과 연결하여 문서화합니다.
