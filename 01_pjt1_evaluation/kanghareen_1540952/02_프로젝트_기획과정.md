# SafeWalk Scout 프로젝트 기획 과정

## 1. 초기 아이디어

초기에는 자율주행 로봇이 일반 보도블록의 파손과 단차를 탐지하고 관리자에게 전달하는 서비스를 고려했습니다.

그러나 일반 보도블록 전체를 대상으로 하면 탐지 클래스가 지나치게 많아지고, 프로젝트의 사회적 가치와 차별성이 약해질 수 있다고 판단했습니다.

## 2. 주제 변경

팀 논의와 피드백을 통해 점자블록을 주요 대상으로 변경했습니다.

### 변경 이유

- 점자블록은 시각장애인의 이동과 직접 연결되는 핵심 보행시설입니다.
- 파손·누락·마모 시 방향 안내 기능이 저하되고 낙상 위험이 발생할 수 있습니다.
- 특정 시설물에 집중함으로써 AI 학습 범위와 MVP를 명확히 할 수 있습니다.
- 향후 일반 보도블록과 다른 보행시설로 확장할 수 있습니다.

## 3. 최종 서비스 정의

SafeWalk Scout는 제한된 보행구역을 자율주행하며 점자블록을 촬영하고, Edge AI가 파손 의심 데이터만 선별하여 위치 정보와 함께 서버로 전송하는 시스템입니다.

서버는 파손 정도와 보수 필요성을 분석하고, 관리자는 지도에서 위치·이미지·처리 상태를 확인합니다. 분석 결과는 점검 결과서와 보수 검토 신청서 초안 생성에 활용합니다.

## 4. 핵심 사용자

### 1차 사용자

- 시청·구청 도로관리 부서
- 안전관리 부서
- 시설관리 담당자

### 최종 수혜자

- 시각장애인
- 저시력자

## 5. MVP 범위

### 필수 범위

- 제한 구역 자율주행
- 장애물 감지 및 정지
- 점자블록 영상 촬영
- 점자블록 파손 유무 탐지
- 정상 영상 자동 폐기
- 파손 이벤트와 위치 정보 서버 전송
- 관리자 지도 표시
- 처리 상태 관리
- 행정문서 초안 생성

### 향후 확장 범위

- 파손 유형 세분화
- 들뜸 및 단차 정밀 측정
- 점자블록 설치 방향 오류 탐지
- 보수 전후 비교 및 악화 추이 분석
- 일반 보도블록·횡단보도·공원 보행로 점검

## 6. 핵심 차별성

단순 자율주행 로봇 제작에 그치지 않고, 다음 과정을 하나의 서비스로 연결합니다.

> 자율주행 점검 → Edge AI 데이터 선별 → 서버 정밀 분석 → 지도 기반 관리 → 행정문서 초안 생성
