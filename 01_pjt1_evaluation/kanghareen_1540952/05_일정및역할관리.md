# 일정 및 역할 관리

## 1. 6주 구현 일정

| 주차 | 주요 내용 | 주요 결과물 |
|---|---|---|
| 1주차 | 주제 선정 및 기획 구체화, 기준 조사, 시스템 설계, 역할 분담 | 최종 기획서, 요구사항, 시스템 구성도 |
| 2주차 | RC카 기본 제작, 데이터 수집·라벨링, FE·BE 초기 설계 | 기본 주행, 1차 데이터셋, 와이어프레임·API 초안 |
| 3주차 | 자율주행 고도화, AI 모델 학습, Jetson 적용, 웹 기능 개발 | 파손 탐지 모델, 주요 API·화면 |
| 4주차 | 시연 환경 구축, RC카 최종 제작, 전체 기능 통합 | 통합 시제품, 관리자 웹 통합 화면 |
| 5주차 | 통합 시연, 오탐·미탐 개선, 문서 생성, 영상 포트폴리오 | 관리자 웹 MVP, 시연 영상 |
| 6주차 | 최종 점검 및 발표 준비 | 발표 자료, 대본, 최종 시연 |

## 2. 역할 분담 방향

- 팀장·PM: 일정 관리, 기획, 회의 진행, 산출물 관리
- 임베디드·자율주행: RC카, 센서, 장애물 감지, 주행 제어
- AI·데이터: 데이터 수집·라벨링, 모델 학습·평가
- 백엔드: API, DB, 파손 데이터 및 문서 생성 로직
- 프론트엔드: 관리자 지도, 목록, 상세, 상태 관리 화면
- 하드웨어 통합: 전원, 배선, 센서 장착, 최종 조립

## 3. PM 관리 원칙

- 모든 기능을 필수·선택 기능으로 분리합니다.
- 각 트랙의 주간 결과물을 명확히 정의합니다.
- 기능 간 연동 규격을 API와 데이터 형식으로 사전에 합의합니다.
- 회의에서 정해진 내용을 즉시 문서와 일정에 반영합니다.
- 4주차 이전에 개별 기능 테스트를 완료하고 통합을 시작합니다.
- 6주차는 신규 개발보다 발표와 안정화에 집중합니다.
- Notion, Google Sheets 등을 활용하여 프로젝트를 관리합니다.
