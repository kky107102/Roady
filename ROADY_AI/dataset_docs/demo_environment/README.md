# 시연환경 점자블록·파손 데이터셋

Jira: [S15P11A404-261](https://ssafy.atlassian.net/browse/S15P11A404-261)

실제 시연 장소에서 휴대폰과 로봇 카메라로 촬영한 이미지를 이용해 Edge AI의 점자블록 및 파손 후보 탐지 성능을 개선하기 위한 데이터셋이다.

## 클래스

| ID | 클래스 | 설명 |
|---:|---|---|
| 0 | `tactile_block` | 화면에서 확인되는 점자블록 영역 |
| 1 | `damage_candidate` | 큰 결손, 작은 결손, 마모, 균열 등 서버 정밀 분석이 필요한 파손 후보 |

흙, 낙엽, 그림자, 얼룩은 `damage_candidate`로 라벨링하지 않고 Hard Negative로 관리한다.

## 파손 유형 메타데이터

- 큰 결손: 점자블록의 큰 일부 또는 전체가 유실된 상태
- 작은 결손: 점자블록 일부가 국소적으로 유실된 상태
- 마모: 돌기 또는 선형 유도부가 닳아 기능 저하가 의심되는 상태
- 균열: 표면에 갈라짐이 확인되는 상태

Edge 모델은 위 유형을 모두 `damage_candidate` 단일 클래스로 탐지하며, 유형과 심각도는 Server AI가 정밀 분석한다.

## 라벨 형식

Ultralytics YOLO Detect 형식을 사용한다.

```text
class_id x_center y_center width height
```

모든 좌표는 이미지 너비와 높이를 기준으로 0~1 사이로 정규화한다.

## 검수 결과 반영 규칙

1. `true_damage`: 기존 파손 후보 박스를 유지한다.
2. `false_soil`, `false_leaf`, `false_other`: 파손 후보 라벨에서 제거한다.
3. `uncertain`: 자동 학습 라벨에서 제외하고 재검수 대상으로 남긴다.
4. 수동 미탐 박스: `damage_candidate`로 추가한다.
5. 완료 이미지에 판정하지 않은 기존 박스: 잘못된 음성 학습을 막기 위해 기존 후보로 보존한다.
6. 수동 박스와 기존 박스의 IoU가 0.7 이상이면 중복 추가하지 않는다.

## Split 원칙

- 동일 촬영 원본과 증강본은 하나의 Split에만 배치한다.
- 연속 프레임과 동일 촬영 그룹을 Train/Validation/Test에 나누어 넣지 않는다.
- 고정 Val/Test에 포함된 원본 10장은 교정 학습에서 제외한다.
- 현장 테스트 100장은 기존 학습·검수 완료·Val/Test 원본과 겹치지 않게 선정한다.
- Test 라벨은 모델 또는 임곗값 선택에 사용하지 않는다.

## 데이터 증강

실제 로봇 주행 상황을 모사하는 약한 증강만 적용한다.

- 밝기·채도·노출 변화
- 약한 모션 블러
- 약한 원근 및 위치 변화
- Edge ROI 오차를 모사한 Crop Jitter

과도한 회전, 강한 Mosaic, 파손 형상을 왜곡하는 변환은 사용하지 않는다.

## 학습 결과

모델: `YOLO26n Detect`, 입력 크기 768, batch 16

| Test 파손 후보 지표 | 기존 모델 | 검수 반영 모델 |
|---|---:|---:|
| Precision | 0.901 | 0.846 |
| Recall | 0.731 | 0.769 |
| F2-score | 0.760 | 0.783 |
| mAP50 | 0.837 | 0.854 |
| mAP50-95 | 0.631 | 0.615 |

Edge AI의 목적은 파손 후보를 놓치지 않고 Server AI에 전달하는 것이므로 Recall과 F2-score가 상승한 검수 반영 모델을 우선 사용한다.
