# Roady 탐지 검토·보수 관리 최종안

## 1. 메뉴와 역할

- `탐지·사건 관리`를 `탐지 검토`로 변경한다.
- `보수 요청 이력`을 `보수 관리`로 변경한다.
- 탐지 검토는 AI 결과를 관리자가 확인하고 최종 판정하는 공간이다.
- 보수 관리는 `보수 필요`로 확정된 사건의 요청부터 완료까지 관리하는 공간이다.

## 2. 핵심 상태

### 관리자 검토 상태

| 화면 표시 | 코드 | 의미 |
| --- | --- | --- |
| 미확인 | `PENDING` | 관리자 판정 전 |
| 확인 완료 | `CONFIRMED` | 보수 필요 또는 불필요 판정 완료 |

`미확인/확인` UI는 상태를 직접 변경하는 토글이 아니라 목록을 구분하는 조회 탭이다.

### 관리자 보수 판정

| 화면 표시 | 코드 |
| --- | --- |
| 보수 필요 | `REQUIRED` |
| 보수 불필요 | `NOT_REQUIRED` |

### 보수 진행 상태

| 화면 표시 | 코드 |
| --- | --- |
| 검토 완료 | `REQUESTED` |
| 보수 중 | `REPAIR_IN_PROGRESS` |
| 보수 완료 | `REPAIR_COMPLETED` |
| 취소 | `CANCELED` |

## 3. 탐지 검토

### 목록

- 상단에 `미확인/확인` 탭을 배치한다.
- 기간, 지역, 우선순위, 파손 유형으로 조회한다.
- 미확인 카드에는 `AI 제안 · {우선순위}` 태그를 표시한다.
- 확인 카드에는 관리자가 확정한 우선순위를 표시한다.
- 확인 카드 우하단에는 `확인 완료`를 표시한다.

### 사건 상세

- 사건번호, 사건명, 위치, 탐지 일시, 이미지를 표시한다.
- AI 분석 결과로 우선순위, 파손 유형, 파손률, 신뢰도를 표시한다.
- 미확인 사건에는 `보수 불필요`, `보수 필요` 버튼을 한 줄에 배치한다.
- 확인 사건에는 관리자 판정, 확인자, 확인 일시와 `판정 수정` 버튼을 표시한다.
- 이미지를 누르면 중앙 이미지 뷰어를 열고 여러 장을 이전/다음으로 이동한다.

### 보수 불필요

1. 확인 모달을 연다.
2. 확인하면 관리자 판정, 확인자, 확인 일시를 저장한다.
3. 사건을 `확인` 목록으로 이동한다.
4. 보수 관리 사건은 만들지 않는다.
5. 처리 결과 알림을 표시한다.

### 보수 필요

1. 관리자 판정 모달을 연다.
2. 사건명, 우선순위, 파손 유형은 AI 제안값을 기본값으로 제공한다.
3. 관리자가 수정 후 확인하면 AI 원본과 별도로 관리자 확정값을 저장한다.
4. 사건을 `확인` 목록으로 이동한다.
5. 보수 관리에 `검토 완료` 사건을 자동 생성한다.
6. 처리 결과 알림에 해당 보수 사건으로 이동하는 `바로가기`를 제공한다.

## 4. 판정 수정

- 확인된 사건에서도 `판정 수정`을 제공한다.
- 변경 전후 값, 변경자, 변경 일시, 변경 사유를 이력으로 남긴다.
- `보수 불필요 → 보수 필요`이면 `검토 완료` 보수 사건을 생성한다.
- `보수 필요 → 보수 불필요`이면 연결된 보수 사건을 삭제하지 않는다.
- 검토 완료·보수 중 단계에서는 사유를 입력하고 보수 사건을 취소할 수 있다.
- 접수 완료 이후에는 경고와 변경 사유를 필수로 한다.
- 보수 중에는 별도 중단 절차를 사용하고, 보수 완료 기록은 삭제하지 않는다.

## 5. 보수 관리

### 목록

- 기간 조회와 담당 지역을 제공한다.
- `검토 완료/보수 중/보수 완료` 탭을 제공한다.
- 우선순위 높은 순, 오래된 순, 최신 순, 최근 변경 순으로 정렬한다.
- 각 행에 우선순위, 사건번호, 사건명, 현재 상태, 최근 변경일, 상세보기를 표시한다.

### 상세

- 뒤로가기, 사건번호, 사건명, 단계 진행 바를 표시한다.
- 탐지·요청·진행·완료 이미지를 종류별 라벨과 함께 표시한다.
- 위치, 일시, 우선순위, 파손 유형, 담당자 정보를 표시한다.
- 검토 완료에는 `요청서 작성`을 제공한다.
- 보수 중 이후에는 `요청서 확인`을 제공한다.
- 보수 완료에는 `완료 보고서`를 추가로 제공한다.

## 6. 데이터 원칙

- AI 제안값과 관리자 확정값을 분리해 저장한다.
- 현재 판정은 수정할 수 있지만 이전 판정은 삭제하지 않는다.
- 보수 사건과 요청서·완료 보고서도 삭제 대신 상태와 이력을 보존한다.
- 우선순위 코드는 `URGENT/HIGH/NORMAL/LOW` 중 하나로 통일한다.

- `roady-ui-concept.png`: Figma 캔버스에 드래그해 시각 시안 참고용으로 사용한다.
- `roady-wireframe-overview.png`: 전체 구조와 흐름을 빠르게 공유하는 참고 이미지다.
- `roady-wireframe-figma.svg`: Figma의 `File → Place image`로 가져오거나 캔버스에 드래그한다.
- SVG를 가져온 뒤 그룹을 해제하면 화면 영역, 텍스트, 버튼, 상태 흐름을 개별 요소로 편집할 수 있다.
- SVG가 사용하는 `Pretendard`가 설치되지 않은 환경에서는 Figma가 `Noto Sans KR` 또는 기본 한글 글꼴로 대체한다.
